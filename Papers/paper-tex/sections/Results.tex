\subsection{Statistical Validation}
ANOVA analysis confirmed statistical differences between the four prompting strategies, demonstrating that structured approaches outperform basic prompting. As expected, the Raw Prompt served as an effective baseline, showing the poorest bias reduction performance and validating the need for structured prompting approaches. Few-Shot with Verification emerged as the top performer, while System Prompt also demonstrated strong bias mitigation capabilities. Few-Shot without verification showed lower performance, confirming that the self-correction mechanism provides meaningful improvement over examples alone.
